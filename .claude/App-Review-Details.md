# FilersHub — GHL Marketplace App Review Checklist

## Overview
Before FilersHub can go public on the GHL Marketplace, we need to submit an **App Review** with the following items. This doc tracks what's needed, what's done, and who owns each piece.

---

## Required Submissions

### 1. End-to-End Demo Video (Required)
- **Status:** ⬜ Not Started
- **Owner:**
- **What GHL wants:** A video walkthrough demonstrating the full app experience — installation flow, connection flow, and the entire end-to-end user journey.
- **What to cover:**
  - Installing FilersHub from the Marketplace
  - Connecting the app to a sub-account
  - Dashboard overview (real-time return stats, workflow management, announcements)
  - Client portal experience (client login, viewing returns, uploading documents, tracking status)
  - Document management (uploading, categorizing, searching)
  - Pipeline / return stages (10-stage flow from Intake Received → Accepted)
  - Chrome extension sidebar
  - Settings (firm branding, portal welcome message, logo upload)
  - Workflow triggers and actions (Add Client, Create Tax Return)
- **Upload to:** Unlisted YouTube or Loom link
